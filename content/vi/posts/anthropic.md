# Giá Claude API được tính như thế nào?

Claude API không hoạt động giống một gói đăng ký cố định hàng tháng.

Chi phí chủ yếu phụ thuộc vào:

- Input Tokens;
- Output Tokens;
- Số lượng API request;
- Model Claude được sử dụng.

Token là đơn vị mà AI sử dụng để xử lý và tạo nội dung.

Hiểu đơn giản:

- Câu hỏi ngắn → dùng ít Token;
- Phân tích tài liệu dài → dùng nhiều Token;
- Hội thoại nhiều lượt → cần nhiều Context hơn.

Vì vậy, hai ứng dụng cùng dùng Claude API nhưng có cách triển khai khác nhau có thể có mức chi phí hoàn toàn khác nhau.
