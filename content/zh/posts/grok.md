# xAI Grok SuperGrok会员订阅、额外使用量付款、续订与取消完整教程

Grok 的付费体系在 2026 年已经比早期复杂不少。

过去很多用户理解的逻辑很简单：

**免费版不够用 → 开 SuperGrok → 每个月自动续费。**

现在则多了几个需要单独理解的概念：

**SuperGrok订阅**

**SuperGrok Plus / Heavy等更高等级方案**

**Weekly Usage Limit 周使用额度**

**Extra Usage Credits 额外使用量**

**Auto Top Up 自动补充额度**

以及：

**网页、App Store、Google Play 三套不同的订阅管理入口。**

如果平时只是偶尔聊天，这些区别可能不明显。

但对于经常使用 Grok Chat、Imagine、Voice、Build，或者用 Grok 做大量内容生成、图片视频和开发任务的人来说，真正影响每月费用的已经不仅仅是“会员多少钱”。

还要看：

**会员包含多少用量、超额以后怎么继续使用、额外额度怎么扣款，以及是否开启了自动续订和自动充值。**

如果你没有方便的国际银行卡，或者希望把 Grok、ChatGPT、Claude 等 AI 服务的消费单独管理，可以考虑使用 **CoinePay Visa / Mastercard 虚拟信用卡**作为一套独立的 AI 订阅支付工具。

下面就把这几个容易混淆的问题分开讲。

---

## 一、SuperGrok现在并不是唯一一个付费档位

xAI 当前官方价格页面显示，个人用户可以从免费版开始，也提供多个 SuperGrok 付费层级。

截至 2026 年 9 月，官方公开页面显示：

**SuperGrok：30美元/月**

主要提供更高的使用额度、Grok 4.6、Grok Bot、Connectors、Expert、图片和视频生成等能力。

**SuperGrok Plus：100美元/月**

在 SuperGrok 基础上增加显著更高的 Chat、Imagine、Voice、Build 使用量，同时提供 1080p 视频生成、优先访问和更快响应等能力。

xAI 当前价格比较页还列出了 SuperGrok Lite、SuperGrok Heavy 等层级，具体可用套餐、价格和功能可能根据账户及地区调整，因此真正购买时应以自己在 grok.com 看到的当前报价为准。

这里有一个很重要的判断方式：

**不要只比较“哪个会员更贵”。**

应该比较：

> 自己一周实际会用掉多少 Grok 额度。

因为 2026 年之后，SuperGrok 的使用方式已经发生明显变化。

## 二、2026年的SuperGrok开始采用“周使用额度”

这是现在理解 Grok 付费体系最重要的一点。

xAI 官方 FAQ 说明，从 2026 年 6 月开始，Grok 针对付费用户逐步采用一个统一的：

**Weekly Usage Pool**

也就是周使用额度池。

以前不同功能可能分别存在自己的每日限制。

例如：

Chat 用完了；

Imagine 还有额度；

Voice 又是另一套限制。

现在则变成：

**一个共享的周额度池。**

你可以把这周包含的使用量用在：

Chat；

Imagine；

Voice；

Build；

以及其他支持的 Grok 产品上。

这种方式更灵活。

但也意味着，如果某一天大量生成高成本内容，也可能提前消耗掉整个星期的会员额度。

---

## 三、一条Chat消息和生成一段高清视频，消耗并不一样

Weekly Usage Pool 并不是按：

“发送100条消息”

这种简单方式计算。

xAI 官方说明，不同 Grok 功能根据所需要的计算资源，会消耗不同程度的使用额度。

比如：

普通聊天通常消耗相对较少；

高质量视频生成会使用更多计算资源；

长时间 Coding / Build 任务也可能明显增加使用量。

因此两个同样购买 SuperGrok 的用户：

A 用户每天主要文字聊天；

B 用户大量生成视频和运行复杂 Build 任务；

最终到达周限制的速度可能完全不同。

这也是为什么现在判断：

**SuperGrok够不够用**

不能只看每天打开 Grok 几次。

更应该看具体使用的产品类型。

## 四、在哪里查看SuperGrok还剩多少使用量？

xAI 已经把用量查看放进账户设置。

进入 Grok 后，可以找到：

**Settings → Usage**

官方当前说明，这里会显示：

当前周额度已经使用的百分比；

不同产品分别消耗了多少；

Weekly Reset 的日期和时间；

Extra Usage Credits 剩余余额。

对于重度用户，我非常建议定期看这个页面。

因为它可以回答三个实际问题：

**我为什么这么快就到限额？**

**到底是Chat还是Imagine最费额度？**

**应该继续买Extra Usage，还是直接升级套餐？**

如果完全不看 Usage，最容易发生的情况就是：

月底发现 AI 支出明显增加，却不知道钱到底花在了哪里。

## 五、如果周额度用完，会发生什么？

到达 SuperGrok Weekly Usage Limit 后，并不等于账户被停掉。

根据 xAI 当前规则，付费能力会暂时受到周额度限制，但你仍然可以继续使用 Grok 免费层中对应的 Chat 和 Voice 免费额度。

同时，你有三种选择。

### 第一种：等下一周自动重置

如果不是急用，可以直接等待 Weekly Usage Pool Reset。

这是最省钱的方法。

### 第二种：购买Extra Usage Credits

如果任务正在进行，不想等，可以额外购买使用额度。

### 第三种：升级到更高套餐

如果你几乎每周都到限额，那么一直充值 Extra Usage Credits 可能并不是最划算的方式。

xAI 官方也明确说明：

经常超出当前套餐用量的用户，升级到更高级方案通常比长期重复购买额外额度具有更好的单位使用成本。

## 六、Extra Usage Credits到底是什么？

可以把它理解成：

**会员包含用量之外的额外付费额度。**

你已经有 SuperGrok。

本周会员包含额度全部用完。

但还要继续生成图片、视频、跑 Build 或使用其他付费功能。

这时候可以购买：

**Extra Usage Credits**

来继续使用。

xAI 当前官方 FAQ 说明：

额外额度会在购买后立即加入账户；

只有当套餐本身包含的 Weekly Usage 已经用完后，才开始消耗这些 Extra Usage Credits；

当前充值额度通常在购买后一年到期，除非页面另有说明；

网页端最低可以从 **5美元**开始购买。

这和会员续费是两个完全不同的消费。

## 七、一个最容易混淆的问题：会员费和Extra Usage不是一回事

例如：

你每月支付 SuperGrok 订阅费。

这个费用换来的主要是：

更高级别功能；

以及套餐包含的 Weekly Usage。

但如果这一周已经用完，然后又额外购买 20 美元 Usage Credits，

那么账单逻辑就变成：

**SuperGrok Subscription**

- 

**Extra Usage Credits**

所以一个重度 Grok 用户每个月的实际费用可能不是固定的 30 美元。

例如：

SuperGrok：30美元

额外额度：20美元

再额外购买：15美元

当月实际 Grok 支出就可能更高。

这也是为什么现在使用 Grok，最好把：

**订阅预算**

和

**使用量预算**

分开看。

## 九、Auto Top Up是什么？打开之前一定要看清楚

如果你不希望 Grok 在工作过程中因为 Extra Usage Credit 不足突然停止，可以开启：

**Auto Top Up**

自动补充。

它的逻辑大致是：

当 Extra Usage Credits 余额下降到设置条件时，系统自动购买额外额度。

xAI 当前允许用户自己设置：

**每次Top Up金额**

以及：

**Monthly Cap 每月最高额度。**

这个功能非常适合：

大量使用 Grok 做内容；

长期跑 Build；

图片视频生产；

团队高频使用。

但普通用户最好不要什么都不看就打开。

## 十、开启Auto Top Up时，Monthly Cap非常重要

假设你设置：

每次自动补充 20 美元。

如果没有合理控制每月预算，在高使用量情况下可能多次触发充值。

“即使这个月使用量特别高，我额外最多愿意花多少钱？”

先确定这个数字。

这比：

“先打开，月底再看账单”

更加适合 AI 服务。

因为视频生成、Build 等高计算资源任务的额度消耗可能比普通聊天快得多。

卡片状态正常；

余额足够；

卡片没有被冻结；

账户 Billing Information 没有异常。

**SuperGrok Extra Usage Credits**

**xAI API Credits**

Extra Usage Credits 主要服务于：

Grok消费者产品中的额外使用。

xAI API / Cloud Console

给 Grok 买 20 美元 Extra Usage

API账户自动多20美元余额。

反过来也一样。

**会员套餐**

- 

**Weekly Usage Pool**

- 

**可选Extra Usage**

-

**“Grok神卡。”**

**固定会员费**

**额外使用费**

**自动补充额度**

三部分。

**Grok Monthly Cap**

和

**虚拟卡自身预算控制**
